# SaveVault

Backup e **restauração inteligente** de saves de jogos: PC (Steam, GOG, Epic, avulsos) **e emuladores**
(PPSSPP, DuckStation, PCSX2, Sudachi, Eden, Xenia e afins) no mesmo app.

Nome provisório. O diferencial não é o backup, é a **restauração**: você aponta a pasta do emulador
(ou instala o jogo de novo) e o app descobre sozinho onde cada save tem que voltar.
